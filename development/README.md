# Development

All material needed to inspect, test and rebuild TwitchPlus is organized here.

- [Build guide](BUILD.md)
- [IPA tester](IPA-TESTER.md)
- [Current release metadata](release.json)
- [Release notes](releases/v1.5.md)
- `src/`: shipping custom source and playlist engine
- `tests/`: host, packaging and UIKit fixtures
- `tools/`: build, packaging and inspection scripts
- `third_party/`: upstream attribution
- `archive/`: superseded design/release notes
- `release-records/`: release/asset metadata and build diagnostics retained before cleanup

The original stable v1.4 IPA remains on GitHub because the packaging workflow uses it as its verified base. Historical source tags remain available even where prerelease downloads were removed. No signing credentials are stored here.
